⚙️ 측정 설정

API 조회에는 인터넷 연결이 필요합니다. GPS와 마이크는 브라우저·운영체제의 권한과 기기 지원 여부에 따라 동작합니다. 기록은 이 브라우저의 IndexedDB에 보관되며 CSV로 내보낼 수 있습니다. 저장공간 정리나 사이트 데이터 삭제 시 사라질 수 있으므로 CSV 백업을 권장합니다.

🧪 현장 보정 메모

마이크의 저주파 에너지는 풍속의 직접 측정값이 아닙니다. 동일한 기기·케이스·방향에서 기준 풍속계와 동시에 측정한 후 검증된 모델을 구축해야 합니다. 현재 버전은 저주파 특징량만 제공합니다. GPS 고도와 API 격자 고도의 차이는 표시하지만 기압·기온에 임의 보정은 적용하지 않습니다.
측정 이벤트가 여기에 표시됩니다.
데이터 해석 및 개인정보 안내
GPS 고도는 기기 및 환경에 따라 오차가 크고, 기압은 Open-Meteo의 격자 지면기압입니다. API의 풍속은 10m 높이의 모델값이며 스마트폰 주변의 실제 순간 풍속과 다를 수 있습니다. 일사량은 시간대별 모델값입니다. 풍향은 기기가 향하는 방향이나 GPS 이동 방향이 아닌 Open-Meteo 10m 모델 풍향(바람이 불어오는 방향)입니다. 위치 좌표는 API 조회 시 Open-Meteo에 전송되며, 별도 자체 서버나 PostgreSQL에는 전송하지 않습니다. 브라우저 기록은 서버에 업로드되지 않습니다.
