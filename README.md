# Smart Weather Lab v3.2 — 그래프 회귀 오류 수정

## 확인된 핵심 원인
v3.0에서 추가한 보정 기능의 `let calPoints` 선언보다 먼저 초기 `show()`가 호출되어 `ReferenceError: Cannot access calPoints before initialization`이 발생했습니다. 이 오류로 초기화 코드가 중단되고, IndexedDB 복원 및 이후 일부 그래프 관련 동작이 영향을 받았습니다. 선언 순서를 수정했습니다.

## 개선
- 마이크 그래프가 활성화되면 1초 간격으로 마이크 지표를 관측 추이 그래프에도 반영합니다.
- 관측 추이는 데이터가 없을 때 안내, 1개일 때 점, 2개 이상일 때 선을 표시합니다.
- v3.1의 돌풍 API 수정 유지.
- 서비스 워커 캐시 버전을 v3.2로 변경하여 기존 PWA 캐시와 구분.

## 배포
ZIP의 내용물을 GitHub 저장소 루트에 업로드하여 기존 파일 교체, Commit. GitHub Pages 배포 후 새로고침. 구 버전이 계속 나오면 Chrome 사이트 설정에서 해당 사이트의 저장된 데이터/서비스 워커를 삭제하면 로컬 기록도 지워질 수 있으므로 **먼저 CSV 백업**하세요.

마이크는 HTTPS, 권한 허용 및 사용자 버튼 조작이 필요합니다. 실측 풍속(m/s)과 마이크 잡음 지표는 다릅니다.
